# 🚀 IFMT - Projeto Next.js com Firebase

Este é um projeto desenvolvido com [Next.js](https://nextjs.org/) e integrado ao [Firebase](https://firebase.google.com/), focado na gestão de dados para o IFMT Campus Campo Verde.

## 🛠️ Tecnologias Utilizadas

* **Framework:** Next.js 14+ (App Router)
* **Banco de Dados:** Firebase Firestore
* **Autenticação:** Firebase Auth (Google Provider)
* **Estilização:** Tailwind CSS
